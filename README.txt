浜名ヤンキース 広報アプリ v4

重要：ChatGPTの添付ファイルプレビューやiPhoneのQuick LookではJavaScriptが無効化される場合があるため、「プロンプトを作る」などが動かないことがあります。
このv4は、通常のHTTPS Webサイトとして公開してSafari/Chromeから使う前提のPWAです。

改善点
- 体験会：最大5日分の日付＋時間帯
- 時間帯：12:30〜15:30 / 8:30〜11:30 / 8:30〜15:30 / その他
- 場所：内野小学校を初期設定 / 自由入力
- 体験会の文章・画像に「※雨天は中止することもあります」を固定
- 入力内容を自動保存
- iPhoneで他アプリへ移動→戻った時に状態復元
- エラー時に画面上へ警告表示
- PWA用manifest / service worker同梱

※写真・動画ファイルはブラウザの安全仕様上、再読み込み後には自動復元できません。日付・時間・文章・場所などは復元します。
