# 浜名ヤンキース｜道具チェック
練習試合・公式戦・河川敷練習の持ち出しチェックアプリ。既存の広報アプリとは別に `gear-check/` 配下で管理しています。

## 使い方
1. ページを開き、練習試合／公式戦／河川敷練習を選ぶ。
2. 夏仕様（4〜10月）・冬仕様（11〜3月）は自動選択。手動切替も可能。
3. 器具庫1・2から道具を取り出したらチェックする。
4. チェックは日本時間の日付と活動・季節ごとに各端末内へ保存する。翌日は新しいチェックになる。

## 初期設定と制約
- 河川敷練習（夏）18品目を登録。冬は夏を暫定コピーしてテント2つ。
- 練習試合・公式戦の持ち物は未確定のため未登録。
- 「管理者向け」設定ボタンはチェック画面の最下部。**認証・アクセス制御は未実装**。
- チェック状況と管理者画面で編集した持ち物設定は、そのブラウザの localStorage に保存される。別のスマホには自動で同期されない。
- **保護者全員の持ち物マスターを更新する場合はリポジトリの初期リストを更新して配布するか、将来、認証付きの共有データベースを導入する必要がある**。
- GitHub Pagesは通常公開URL。選手の個人情報や非公開データを書き込まない。
